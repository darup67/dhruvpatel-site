# dhruvpatel-site

Personal and professional site for Dhruv Patel: https://darup67.github.io/dhruvpatel-site/

Plain HTML and CSS with a few lines of JavaScript for the theme toggle. No build step, no trackers, no third-party requests.
Hosted free on GitHub Pages from the `main` branch.

```
index.html   content and structure
style.css    light and dark themes, responsive layout
script.js    theme toggle
resume/      downloadable resume (PDF)
```
